# Locale keys

`en.json` supplies the plugin manager's title, description and detail link for one bundle: `meta.title` is the
row in the plugin list, `meta.description` is its tooltip, and `meta.detail` is the document the row opens.
A bundle adds `de.json` beside it for another language, and `package.json` exports the folder with
`"./locale/*.json"`. The behavior the strings describe: [the gate](../../../.agents/AUTO-RAG.md).
