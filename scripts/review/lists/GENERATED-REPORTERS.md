# Generated reporters index

Generated by `python -m scripts.review.lists.entry_points --kind report --markdown`; do not edit by hand.

- `scripts.review.limits`: Every numeric rule in one place: the limit, the current edge, and the exceptions each one accepts.
- `scripts.review.lists.entry_points`: Every runnable entry point under tools/ and review/: what it is for, kept current by test.
- `scripts.review.lists.index_status`: Report both code index sizes from their live stores, so no document has to quote them.
- `scripts.review.lists.manual_gates`: Live inventory of the manual-run guard: every place that references it, computed from source.
- `scripts.review.restrictions`: Print the agent restrictions, read from their owners instead of restated here.
- `scripts.review.ruff_ignores`: Count ruff suppressions: global ignores, per-file ignores and inline noqa comments.
- `scripts.review.tree_sizes`: Say which local trees are expensive and whether git ignores them, since the agent guard reads those files.
- `scripts.review.voice_references`: Reference-clip quality for the clone voices: sound annotations, scene text and broken characters.
- `scripts.tools.local_work`: List the local work this repository carries outside git, so a reader can review all of it in one place.
- `scripts.tools.locate_files`: Find files by suffix under the repository's known roots, without walking the whole data tree.
- `scripts.tools.rocm_inventory`: Inventory ROCm installs on this machine: location, kind, version, size and project references.
- `scripts.tools.yaml_table`: Print a YAML list of mappings as a table.
