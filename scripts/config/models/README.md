# Model catalog

- Source of truth: [catalog.json](catalog.json) (version 1). One entry per model; edit through `scripts.tools.model_admin` or the JSON directly.
- Fields: `category` (`llms`/`asr`/`tts`/`images`), `group` (component owner), `label` (canonical id), `filename` (relative to that component's `models_dir`), `url`, `in_use`, `notes`, `sha256`, `roles`, `runtimes`, `source_page`.
- `catalog.py` validates uniqueness, ownership and relative destinations, then computes the absolute destination through `project_cfg.model_destination(group, filename)`.
- `ids.py` is generated by `catalog.write_ids()` or `model_admin`; never edit it by hand.
- `llms.py` / `asr.py` / `tts.py` / `images.py` are compatibility wrappers around `models_for(category)`.
- Use `models.path(ModelId.X)`, `models.get(...)`, `models.filename(...)`, `models.destination(...)`; `ModelId` is the typed name for a canonical label.

```powershell
python -m scripts.tools.model_admin where "llamacpp/Swift-1.5-Qwen3.8-27B-GSQ-RCO-IQ3_XXS-mtp"
python -m scripts.tools.model_admin add --category llms --group llamacpp --label "..." --filename "coding_models/..." --url "https://..." --in-use --apply --download
python -m scripts.tools.model_admin remove "koboldcpp/TheDrummer_Snowpiercer-15B-v4-IQ4_XS" --apply
python -m scripts.tools.model_admin replace "old/label" "new/label" --apply
python -m scripts.download.models.model_sync
```

Removal and replacement never physically delete weights: they move installed files to `C:/AI/trash/model_admin/<timestamp>/`. If the file is already missing, the catalog and reference cleanup still runs; `replace` warns when the new model is not installed.
